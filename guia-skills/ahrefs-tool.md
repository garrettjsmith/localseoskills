# ahrefs-tool — Análise profunda de links (backlinks) com Ahrefs

## O que é a skill?

É uma skill de **ferramenta**. Ela ensina quando e como usar o Ahrefs, um serviço de SEO (otimização para buscadores) famoso por ter o maior banco de dados de links da internet.

Um **backlink** é um link de outro site que aponta para o seu. Quanto mais links bons, mais o Google confia no site.

## Para que serve?

Serve para estudar a "força de links" de um negócio local e de seus concorrentes. Ela cobre:

- **Perfil de links:** quem aponta para o site e qual a qualidade disso.
- **Lacuna de links (link gap):** sites que linkam para o concorrente, mas não para você. São oportunidades.
- **Links perdidos:** links que sumiram e podem explicar queda no ranking.
- **Texto âncora:** as palavras clicáveis dos links. Se forem muito "forçadas", há risco de penalização.
- **Ideias de conteúdo** que atraem links (Content Explorer).

Ela explica métricas como DR (Domain Rating, nota de 0 a 100 da autoridade do site).

Para uma visão rápida, use antes a LocalSEOData.

## Como utilizar?

**Pré-requisito:** ter o servidor MCP oficial do Ahrefs conectado (MCP é a ponte que deixa a IA usar a ferramenta). Isso exige uma conta no Ahrefs, que é um serviço pago. Os arquivos não citam chaves de API.

**Informe:** o site (domínio) do negócio e, se quiser comparar, os sites dos concorrentes.

**Frases que ativam a skill:**
- "Quem faz link para o meu concorrente e não para mim?"
- "Analise o perfil de backlinks deste site."
- "Por que eles ranqueiam acima de mim?"

## O que ela produz?

Uma análise com dados e orientação, não um arquivo pronto. Ela entrega:

- Leitura do perfil de links (DR, sinais de alerta).
- Lista priorizada de oportunidades: relevância local, autoridade, tipo de link e facilidade.
- Links perdidos para recuperar.
- Avaliação do texto âncora.
- Um próximo passo: dizer se o problema é de links ou de outra coisa.

**Skills relacionadas que ela indica:**
- `local-link-building`: estratégia e contato para conseguir links.
- `local-citations`: oportunidades em diretórios.
- `geogrid-analysis` e `gbp-optimization`: quando links não são o problema (GBP = Perfil da Empresa no Google).
- `client-deliverables`: incluir os dados em relatórios para clientes.
