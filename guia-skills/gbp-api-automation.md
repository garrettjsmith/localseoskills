# gbp-api-automation — Automação do Perfil da Empresa no Google via API

## O que é a skill?

É uma skill de estratégia. Ela orienta como gerenciar muitos Perfis da Empresa no Google (GBP) de forma automática, usando uma API.

API é uma "porta" que deixa um programa conversar com o Google, sem você clicar tela por tela.

A skill atua como especialista em gerenciar de 10 a 500+ unidades com eficiência e segurança.

## Para que serve?

- Atualizar dados de várias unidades de uma vez (horários, descrição, fotos).
- Publicar posts automaticamente, com modelos e variáveis por unidade.
- Monitorar avaliações novas e separar as negativas para resposta rápida.
- Extrair dados de desempenho para relatórios.
- Acompanhar verificação, suspensões e edições indevidas.
- Evitar riscos: mudanças em massa de nome, categoria ou endereço podem causar suspensão (o Google desativa o perfil).
- Decidir entre construir sua própria integração ou usar uma plataforma pronta (Yext, Uberall, Synup, BrightLocal etc.).

## Como utilizar?

**Pré-requisitos:**
- Projeto no Google Cloud, com as APIs do Perfil da Empresa ativadas.
- Credenciais OAuth 2.0 (forma segura de o programa acessar sua conta).
- Acesso ao GBP como Proprietário ou Gerente.
- Aprovação do Google para aumentar os limites de uso (cotas), se necessário.

**Informe à skill:**
1. Quantas unidades precisam de gestão?
2. O que automatizar: atualizações, posts, avaliações ou relatórios?
3. Construir do zero ou usar uma plataforma?
4. Qual é a sua tecnologia atual?
5. Quem cuida do projeto no Google Cloud e das chaves?
6. Como são aprovadas as mudanças em massa?

**Exemplos de frases:**
- "Quero automatizar atualizações do GBP para 80 unidades."
- "Como uso a API do Google Business Profile para postar em várias lojas?"
- "Vale construir uma integração própria ou usar uma plataforma?"

## O que ela produz?

Orientação prática, não um arquivo pronto: o roteiro de automação, os cuidados para não causar suspensão, a estrutura de uma base mestra de unidades e uma lista de alertas por prioridade.

**Skills relacionadas:**
- `gbp-optimization`: definir o que otimizar (faça isso antes).
- `multi-location-seo`: estratégia para várias unidades.
- `gbp-posts`: modelos de posts.
- `gbp-suspension-recovery`: se ocorrer suspensão.
